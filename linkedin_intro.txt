🎓 AI 기반 논문 심사 시스템을 직접 만들었습니다.

논문을 제출하기 전, "과연 이 논문이 통과될 수 있을까?" 라는 질문을 한 번쯤 해보셨을 겁니다.
저도 같은 고민을 하다가, 직접 AI 논문 리뷰어 웹사이트를 개발했습니다.


📌 어떤 사이트인가요?

PDF 또는 DOCX 형식의 논문 파일과 제출 대상 저널/컨퍼런스명을 입력하면,
AI가 실제 학술 심사 기준으로 논문을 분석해 강점·약점·점수·최종 결정을 실시간으로 제공하는 웹 서비스입니다.

CVPR, NeurIPS, ICML, ICLR, IEEE TPAMI, Nature Machine Intelligence 등
주요 컨퍼런스 및 저널 기준에 맞춰 심사가 진행됩니다.


🧠 핵심 구조: 3인 병렬 심사 + Area Chair 최종 판정

단일 AI 리뷰어는 실행할 때마다 결과가 달라지는 일관성 문제가 있습니다.
이를 해결하기 위해 실제 학술 심사 프로세스를 모방한 멀티 에이전트 구조를 설계했습니다.

▸ 검토자 1 — 기술 전문가 (MIT/CMU 스타일)
  방법론의 수학적 엄밀성, 알고리즘 설계, 실험의 과학적 타당성을 중심으로 평가

▸ 검토자 2 — 신규성/영향력 전문가 (Google Brain/FAIR 스타일)
  연구의 독창성, 현재 SOTA 대비 기여도, 분야 발전 가능성을 중심으로 평가

▸ 검토자 3 — 보수적 학자 (KAIST/서울대 스타일)
  논문 완성도, 관련 연구 포괄성, ablation study 충분성을 중심으로 극도로 엄격하게 평가

▸ Area Chair (메타 리뷰어)
  3명의 독립 리뷰를 종합하여 합의점과 불일치점을 조율하고,
  Desk Reject / Major Reject / Minor Reject / Borderline / Weak Accept / Accept / Strong Accept
  중 하나의 최종 결정을 내립니다.

3명의 리뷰어는 서버에서 병렬(멀티스레드)로 동시에 실행되며,
모든 리뷰가 완료된 후 Area Chair가 종합 판정을 수행합니다.


⚙️ 기술 스택

• Backend: Python FastAPI + Server-Sent Events(SSE) 스트리밍
• 병렬 처리: Python threading + Queue로 3개 리뷰어 동시 실행
• AI 모델: OpenRouter API를 통한 대형 언어 모델 활용
  - Meta LLaMA 3.3 70B Instruct
  - NVIDIA Nemotron Super 120B
  - Nous Hermes 3 LLama 405B 외 다수
  - 모델 장애 시 자동 폴백(fallback) 체인으로 안정성 확보
• 문서 파싱: pdfplumber(PDF), python-docx(DOCX)
• Frontend: 바닐라 JavaScript + marked.js(마크다운 렌더링)
  - 4개 탭 UI (최종 판정 / 검토자 1 / 검토자 2 / 검토자 3)
  - 스트리밍 중 실시간 점수 파싱 및 시각화
• 선택 기능: 저널/컨퍼런스 URL 입력 시 크롤링하여 심사 기준에 반영


📊 출력 결과

각 리뷰어별로 아래 항목을 실시간 스트리밍으로 제공합니다.
• 요약 점수표: 신규성 / 기술 완성도 / 실험 품질 / 작성 품질 / 중요도 (10점 만점)
• 핵심 강점 3가지 / 핵심 약점 3가지
• 전문 영역별 세부 평가
• 저자에게 보내는 핵심 질문
• 최종 의견

Area Chair 탭에서는 3인 점수 비교표, 합의/불일치 사항, 최종 결정 및 수정 방향까지 확인할 수 있습니다.


💡 만든 이유

논문 제출 전 피드백을 받을 기회가 제한적인 연구자, 특히 혼자 작업하는 대학원생들이
실제 리뷰어 관점의 날카로운 피드백을 빠르게 받을 수 있도록 하고 싶었습니다.

AI가 실제 심사를 대체할 수는 없지만,
제출 전 논문의 약점을 미리 파악하고 보완하는 데 실질적인 도움이 될 수 있습니다.
